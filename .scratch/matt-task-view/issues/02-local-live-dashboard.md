# 02: 提供本地实时开发任务页面

**What to build:** 用户可以通过一个仅本机可访问的命令打开开发任务页面，页面取得与任务图命令相同的快照；修改任何票据后，已打开的页面会自动取得新进度，无任务与错误状态也有可读页面反馈。

**Blocked by:** 01: 构建可校验的任务图快照.

**Status:** ready-for-agent

- [ ] 服务只监听 `127.0.0.1`，并提供 HTML 页面、只读快照 API 与刷新通知流，不使用外部服务或依赖。
- [ ] 页面在票据新增、删除或内容改变后自动重新请求快照；一个无票据仓库显示空态而不是错误退出。
- [ ] 启动命令清楚输出可在 Codex 右侧浏览器面板打开的本地地址，并拒绝不安全的非回环监听配置。
- [ ] 集成测试验证本地 HTTP 响应、快照内容、文件变动通知和回环绑定。
